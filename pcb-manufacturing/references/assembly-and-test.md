# 装配与测试（assembly-and-test）

## 钢网

| 项 | 建议 |
|---|---|
| 厚度 | 0.12mm（0402 及以上）；0.10–0.12mm 细间距 |
| 开孔 | 按焊盘/间距；QFN 散热焊盘分区 |
| 张力 | 按钢网厂 |
| 清洗 | 按工艺 |

- 细间距/大焊盘的开孔面积比会影响下锡。
- 散热焊盘开孔避免大面积空洞/偏移。

## 首件（FAI）

- 极性/方向（二极管、钽电容、IC pin1、连接器）。
- 偏移/立碑/少件/多件。
- DNP 是否按 BOM/CPL。
- 关键器件位号与装配图一致。

## 测试点

- 直径 ≥1.0mm；间距 2.54mm（`HEURISTIC`）。
- 单面可达优先；双面测试需治具。
- 电源/地/复位/关键总线各留点。
- 测试点不被高器件/外壳遮挡。

## ICT / FCT

| 类型 | 目的 | 要求 |
|---|---|---|
| ICT | 开路/短路/元件值 | 测试点覆盖、探针压力 |
| FCT | 功能 | 治具、烧录、通信 |
| 飞针 | 小批量/原型 | 测试点尺寸/间距 |

- 测试夹具的定位孔/Mark 与拼板一致。
- 测试项与设计规格对应；阈值写清。

## 烧录与调试

- SWD/JTAG/串口引出；防呆。
- 启动模式（BOOT）可切换；默认状态标注。
- 调试口在装配后仍可访问。

## DNP 一致性

BOM、CPL、装配图、丝印四处必须一致：

- BOM：`DNP` 列。
- CPL：是否包含按板厂要求；manifest 说明。
- 装配图：DNP 标识。
- 丝印：必要时标 `DNP`。

## 常见问题

| 问题 | 原因 | 处理 |
|---|---|---|
| 立碑 | 两端热/焊盘不对称 | 改焊盘/走线 |
| 偏移 | 钢网/贴片 | 调开孔/贴片 |
| 少件 | BOM/CPL 不一致 | 对版本/位号 |
| 极性反 | 装配图不清 | 加标识/FAI |
| 测试点不可达 | 被器件挡 | 布局阶段解决 |
| 烧录失败 | 调试口被盖 | 结构/布局避让 |
