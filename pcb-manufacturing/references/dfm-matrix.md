# DFM 矩阵（dfm-matrix）

保守起点；以目标 `fab-profile.json` 的实际能力为准。低于"最小"列必须书面确认。

## 导体与孔

> 孔尺寸为**成品孔径**（镀铜后）；距离为**边缘到边缘**。钻刀尺寸另按板厂补偿。

| 项 | 保守 | 需确认 | 说明 |
|---|---|---|---|
| 线宽 | 0.15mm | <0.127mm | 细线加价/良率 |
| 间距 | 0.15mm | <0.127mm | 与线宽同 |
| 过孔成品孔径 | 0.3mm | <0.2mm | 激光钻另计 |
| PTH 插件孔成品孔径 | 0.3mm | <0.2mm | 按元件引脚 |
| NPTH 成品孔径 | 0.5mm | <0.5mm | 通常大于 PTH；按板厂 |
| 环宽 | 0.15mm | <0.13mm | 按孔径/板厂 |
| 孔铜 | 25µm | <20µm | 按电流/可靠性 |
| 孔到孔（边到边） | 0.5mm | <0.3mm | 防破孔 |
| 孔到铜（边到边） | 0.3mm | <0.2mm | 按板厂 |

某类孔能力未确认时（profile 为 `null`）→ 保持"待确认"，不得套用其他孔型数值。

## 阻焊与丝印

| 项 | 保守 | 说明 |
|---|---|---|
| 阻焊桥 | 0.1mm | 细间距/绿色差异 |
| 阻焊开窗 | 单边 0.05–0.1mm | 按焊盘 |
| 丝印字高 | 0.8mm | 字宽/线宽 ≥0.15mm |
| 丝印到焊盘 | ≥0.15mm | 避免压焊盘 |
| 丝印到板边 | ≥0.3mm | 按板厂 |

## 板边与机械

| 项 | 保守 | 说明 |
|---|---|---|
| 铜到板边 | 0.3mm | 铣刀公差 |
| 器件到板边 | 3–5mm | `HEURISTIC`，按结构 |
| V-cut 剩余厚度 | 按板厂 | 通常 1/3 板厚 |
| 槽孔长宽比 | 按板厂 | 深槽需确认 |
| 拼板尺寸 | 按产线 | 与板厂确认 |

## 阻抗

- 阻抗线宽/间距按叠层算，不在 DFM 表里"猜"。
- 测试 coupon 随板；标注层/线宽/目标。
- 板厂 EQ 确认叠层与阻抗。

## 检查方法

1. 用 `kicad-cli pcb drc` 跑规则（含板厂约束）。
2. Gerber/钻孔用查看器复核：层序、镜像、孔数、槽孔。
3. 阻焊/丝印单独看：桥、压盘、字高。
4. 拼板看 V-cut/工艺边/Mark。
5. 与 fab profile 逐项对照；超差项列 EQ。

## 常见 DFM 失败

| 症状 | 原因 | 修法 |
|---|---|---|
| 细线断/开路 | 线宽贴下限 | 加宽或换板厂 |
| 阻焊桥缺失 | 间距太小 | 改焊盘/开窗 |
| 丝印糊 | 字高/线宽不足 | 加大/简化 |
| 孔破/环宽不足 | 孔太靠边 | 移孔/加环宽 |
| V-cut 伤件 | 槽边放器件 | 移器件/加工艺边 |
| 阻抗超差 | 叠层未确认 | 重算/换叠层 |
