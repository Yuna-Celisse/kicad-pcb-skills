# 原理图评审清单（schematic-review-checklist）

逐项打勾；不适用写 `N/A` 并说明。任何 `block` 项未过不得交棒布局。

## 结构与层次

- [ ] 功能域分页（power / mcu / interface / analog / connector）。
- [ ] 每页标题栏有功能名与版本。
- [ ] sheet pin 方向与被连信号一致。
- [ ] 层次标签名与 sheet pin 完全一致。
- [ ] 跨页信号只走层次标签，未滥用全局标签。

## 命名

- [ ] 无 `Net-(...)` 自动网络名。
- [ ] 电源/地命名统一（`VCC_3V3`、`GND`、`GNDA`）。
- [ ] 差分对成对命名；低有效统一前缀。
- [ ] 一个网络只有一个语义名。
- [ ] 位号无重复、无空号；多单元用 `U1A/U1B`。

## 图面

- [ ] 所有引脚/导线端点落 1.27mm 网格。
- [ ] 无导线穿过符号/文字/引脚名。
- [ ] 四路交叉打点或拆 T；无重叠导线。
- [ ] 电源符号在上去耦就近；地去耦就近。
- [ ] 关键网络有注释（差分阻抗、电流）。

## 电气

- [ ] 每个电源脚有去耦（值/耐压核对）。
- [ ] 每个对外接口有 ESD/限流。
- [ ] 复位/BOOT/调试口完整。
- [ ] 晶振 CL 与 Cstray 核算。
- [ ] I²C 上拉按总线电容核算。
- [ ] CAN 终端可切；USB CC 正确。
- [ ] 未用引脚/门有确定状态或 NC。

## ERC

- [ ] 整树 ERC 已跑（非只根页）。
- [ ] 真错清零；误报有台账记录。
- [ ] `PWR_FLAG` 只加在电源来源网络。
- [ ] 无重复位号、无封装不匹配。

## 可测试性

- [ ] 每个电源域有测试点/测量跳线。
- [ ] 调试口/BOOT 可访问。
- [ ] 跳线/DNP 有默认状态与丝印。
- [ ] 测试点命名与网络一致。

## 机械/评审

- [ ] 符号重叠 `pcb_overlap` 无 block。
- [ ] 连接器方向/针序与结构一致。
- [ ] 板框/安装孔在原理图阶段已确认。
- [ ] 评审问题全部关闭或有负责人。
