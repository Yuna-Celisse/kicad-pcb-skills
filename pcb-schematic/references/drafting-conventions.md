# 图面规范（drafting-conventions）

目标：任何人打开这张图，能在 30 秒内看懂电源流向、信号路径与关键约束。

## 网格与对齐

- 全局 1.27mm（50mil）网格；符号原点、引脚、导线端点、junction 全部落网格。
- 文本、位号、值不要压引脚或导线；旋转文字保持可读方向。
- 同类器件（电阻、电容、连接器）按列/行对齐，间距一致。

## 流向

| 元素 | 方向 |
|---|---|
| 信号 | 左 → 右 |
| 电源 | 从上往下（电源符号在上） |
| 地 | 向下（GND 符号在下） |
| 反馈 | 从输出右侧回折到左侧控制脚 |
| 总线 | 横向主走，分支向下 |

## 连线

- 导线不得穿过符号体、引脚名、文字。
- 四路交叉：打 junction 点；或拆成两个 T 型，避免"十字无点"歧义。
- T 型连接必须打点；两条线端点相接可不必打点，但建议统一打点。
- 不要用"两条线重叠"表示连接——重叠会合并网络，且不可读。
- 导线尽量短、少折；折角 45° 或 90° 统一。

## 标签与电源符号

- 网络标签放在导线上方/右侧，锚点落在导线上。
- 电源符号靠近使用点；不要一页只放一个 `+3V3` 在角落。
- 去耦电容紧贴 IC 电源脚画（图面顺序也表达优先级）。
- 跨页连接用层次标签；全局标签只用于电源/地/真全局信号。

## 层次页

- 每页一个功能域；页名与文件名一致（`power.kicad_sch`）。
- sheet pin 方向与被连信号一致（输入/输出/双向）。
- 层次标签名 = 父页 sheet pin 名；不要靠位置"碰巧连上"。
- 页内不要重复定义父页已定义的电源网络。

## 常见 KiCad 陷阱

| 现象 | 原因 | 处理 |
|---|---|---|
| 导线端点差半格 | 未落网格 | 吸附到 1.27mm |
| 两个网络莫名合并 | 导线重叠/标签锚点重合 | 移开重叠段 |
| 标签不生效 | 锚点不在导线上 | 拖到导线上 |
| 层次页连不上 | 标签名与 sheet pin 不一致 | 统一命名 |
| ERC 报多驱动 | 输出脚并接/测试点 | 分类裁决（见 erc-adjudication） |
| 位号重复 | 复制粘贴未重标注 | 重新 annotate |

## 可读性

- 功能块之间留空，块标题用文字框。
- 关键网络加注（如 `USB_DP 90Ω diff`）。
- 不用的门/单元加 `no_connect`，不要悬空。
- 一页放不下就拆页，不要缩到 50% 还硬塞。

## 评审最小集

1. 电源/地完整，所有电源脚有去耦。
2. 每个网络有语义名；无自动生成名（`Net-(...)`）。
3. 无重叠导线、无未打点 T 型、无穿符号导线。
4. 层次 pin 与标签一致。
5. 符号重叠 `pcb_overlap` 无 block。
