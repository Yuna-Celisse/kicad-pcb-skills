# 块级电路（circuit-blocks）

每个块给出**取值依据**；标 `HEURISTIC` 的是经验值，数据手册优先。

## 电源：LDO

- 功耗：`P = (Vin − Vout) × Iout`；结温 `Tj = Ta + P × θJA`。
- 压差：`Vin(min) ≥ Vout + Vdropout(Iout) + 纹波余量`。
- 输入/输出电容按手册；输出电容 ESR 影响稳定性（老 LDO 尤其）。
- 反馈分压：`Vout = Vref × (1 + R1/R2)`；分压电阻取手册推荐量级。
- EN/UVLO：分压阈值为 `Vin(on)`；加迟滞防抖。
- `HEURISTIC`：LDO 效率低，压差大/电流大时改 DCDC。

## 电源：DCDC（Buck）

- 电感：`L = (Vin − Vout) × Vout / (Vin × fsw × ΔIL)`，`ΔIL` 取 `0.2–0.4 × Iout`。
- 电感 Isat ≥ 1.3 × 峰值（`Iout + ΔIL/2`）；DCR 压降与温升同时核。
- 输入电容承受脉冲电流，靠近 Vin 脚；输出电容按纹波要求。
- 反馈取样在输出电容之后、开尔文接到 FB；远离电感/SW 节点。
- SW 节点铜箔小、短；换流 hot loop 是 **输入电容 → 高侧开关 → 低侧开关 → 回到输入电容**，
  面积最小。电感电流连续，不属于这条高 di/dt 回路。
- 软启动/补偿按手册；轻载模式影响静态电流。

## MCU 最小系统

- 每个电源脚 100nF（`HEURISTIC`）， Bulk 10µF/电源域。
- 复位：RC + 可选复位芯片；复位脚不要悬空。
- BOOT/模式脚：按电平表接固定电阻，标注默认状态。
- 调试口：SWD/JTAG 引出，含 VCC/GND/NRST。
- 未用引脚：按手册接固定电平或配置为输出，不要全部悬空。
- 去耦电容靠近引脚，地过孔就近。

## 晶振

- 负载电容：`CL = (C1 × C2)/(C1 + C2) + Cstray`；C1=C2 时 `C = 2(CL − Cstray)`。
- `Cstray` 取 3–5pF（`HEURISTIC`，按布局估）。
- 串联电阻 `Rs` 抑制过驱（无源晶振按手册/实测）。
- 晶振下方不走线、不铺铜（按器件要求）；包地。
- 负载电容接地就近，不要共用长地。

## USB 2.0 / USB-C

- UFP（设备）：CC1/CC2 各 5.1k 下拉到 GND。
- DFP（主机）：CC 上拉/电流源按规范；不要用 5.1k 上拉。
- VBUS：输入电容 1µF+0.1µF；如需检测用分压，注意耐压。
- D+/D-：串阻 0–22Ω（按 EMC/眼图），ESD 靠近连接器。
- ESD 二极管结电容要满足速率；不要用大电容 TVS 直接并 D+/D-。
- `HEURISTIC`：USB 2.0 差分 90Ω，按叠层核算。

## I²C

- 上拉：`Rp(max) = tr / (0.8473 × Cbus)`；`Rp(min) = (Vcc − Vol) / Iol`。
- `Cbus` 含走线、引脚、器件电容；400kHz 时 `tr` 约 300ns。
- 总线电容上限（规范 400pF）要留余量；多器件时降速或加缓冲。
- 地址冲突在原理图阶段解决（ADR 脚）。
- 上拉只在一处；不要每页都放。

## SPI / UART / CAN

- SPI：片选上拉（默认不选中）；长线加串阻；时钟走线短。
- UART：TX/RX 交叉；电平匹配；长线加 TVS。
- CAN：总线两端各 120Ω（可跳线/可切）；共模电感/ESD；分支短。
- 隔离接口：隔离电源 + 数字隔离器；爬电距离按安规。

## ADC 前端

- 输入 RC：`R` 限流、`C` 采样保持；`R × C` 与采样时间匹配。
- 源阻抗看手册最大推荐；高阻源加缓冲。
- 抗混叠截止频率 < `fs/2`，留过渡带。
- 基准：去耦 0.1µF + 10µF；基准走线远离数字。
- 差分输入按共模范围与偏置。

## 保护

| 保护 | 选型要点 |
|---|---|
| 反接 | P-MOS/理想二极管；Vgs 耐压留 2× |
| 过流 | 保险丝/PPTC；额定电流 ≥ 1.5× 工作 |
| 过压 | TVS 钳位 < 被保护脚 abs max；峰值功率满足浪涌 |
| ESD | 结电容匹配信号速率；靠近入口 |
| 浪涌 | 按测试等级选 TVS/压敏；注意残压 |

## 上电时序

- 多电源域：按手册时序；必要时加 PG/EN 链。
- 先核 POR 与复位释放；避免 IO 早于电源上电。
- 掉电时序同样要检查（反灌风险）。
