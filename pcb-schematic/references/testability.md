# 可测试性（testability）

目标：板子做回来能**测、能调、能烧录**，而不是只能靠猜。

## 测试点

| 信号 | 位置 | 要求 |
|---|---|---|
| 电源轨 | 每个域至少一个 | 焊盘 ≥1.0mm，间距 2.54mm |
| 地 | 靠近测试点 | 低阻抗，单独过孔 |
| 复位/BOOT | MCU 附近 | 可探针，避免被外壳挡 |
| 关键时钟 | 时钟源/负载端 | 短地弹簧优先 |
| 总线 | 每组至少一组 | 按协议留 probe 点 |
| 模拟 | 前端/基准 | 远离数字噪声 |

- 测试点命名与网络一致；丝印标 `TP1 VCC_3V3`。
- 测试点不要放在元件下方或高元件旁。
- 关键电源可留 0Ω/跳线做电流测量。

## 跳线与 0Ω

- 电流测量：0Ω 串入电源轨，测时拆下接表。
- 隔离：模拟/数字地、CAN 终端、USB 屏蔽。
- 配置：地址、模式、电压选择。
- 每个跳线有默认状态与丝印说明（`JP1: 1-2 = 3V3`）。

## DNP 与选项

- DNP 器件保留位号、BOM 标 DNP、丝印可标 `DNP`。
- 不要把"可能不贴"做成口头约定。
- 选项电路（如 CAN 终端）用跳线/0Ω，明确默认。

## 烧录与调试

- SWD/JTAG：VCC/GND/NRST/SWDIO/SWCLK，必要时 SWO。
- 排针间距 2.54mm 或 1.27mm，防呆（缺针/丝印）。
- 串口调试：TX/RX/GND，留测试点。
- 启动模式：BOOT 跳线/按键，标注默认。

## 生产测试

- ICT/FCT：测试点覆盖率、间距、探针压力。
- 飞针：测试点尺寸 ≥1.0mm，双面可达。
- 老化/温循：关键电源与接口留监测点。
- 测试夹具：定位孔、Mark 点、板边禁布。

## 评审清单

1. 每个电源域有测试点/测量跳线？
2. 复位、BOOT、调试口可访问？
3. 关键总线有 probe 点？
4. 测试点不被外壳/高件遮挡？
5. DNP/跳线有默认状态与丝印？
6. 测试点命名与网络一致？
