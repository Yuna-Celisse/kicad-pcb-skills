# 命名与层次（naming-and-hierarchy）

## 网络命名

| 类别 | 形式 | 示例 |
|---|---|---|
| 电源 | `<电压>_<来源/域>` | `VCC_3V3`、`+5V_USB`、`VBAT`、`VCC_1V8` |
| 地 | `GND` / `GNDA` / `GNDP` | 模拟地、功率地只在明确分区时拆 |
| 差分 | `<信号>_P/_N` 或 `_DP/_DN` | `USB_DP/USB_DN`、`CAN_H/CAN_L` |
| 低有效 | `n<名>` 或 `<名>_N` | `nRESET`、`nCS`、`EN_N` |
| 时钟 | `CLK_<频率/用途>` | `CLK_24M`、`CLK_I2S` |
| 模拟 | `AIN_*` / `AOUT_*` | `AIN_TEMP`、`AOUT_GAIN` |
| 控制 | `<功能>_<方向>` | `MOTOR_EN`、`LED_STAT` |
| 总线 | `BUS_<名>[n..m]` | `DATA[0..7]` |

规则：

- 一个网络只有一个语义名；不要用标签"猜"连接。
- 同一电压不同域要分开命名（`VCC_3V3` vs `VCC_3V3_ANA`），并在单点汇合。
- 避免 `Net-(C12-Pad1)` 这类自动名进入评审；发现即补名。
- 名字不带空格/中文；长度控制在 24 字符内。
- 电源网名不要与符号库电源符号冲突（如已有 `+3V3` 就统一用它）。

## 层次划分

推荐五域：

```
power/     电源树、保护、监测
mcu/       主控最小系统、时钟、复位、调试
interface/ USB、UART、I2C、SPI、CAN、以太网
analog/    前端、滤波、基准、ADC/DAC
connector/ 对外接口、ESD、机械
```

- 每域一页；页数超过 6 页时考虑二级层次。
- 页名 = 文件名；标题栏写清功能与版本。
- 电源域在 power 页统一定义，其他页只引用。

## sheet pin

- 方向必须与被连信号一致：输入进、输出出、双向用于总线/数据。
- 名称与页内层次标签完全一致（大小写敏感）。
- 不要用全局标签替代 sheet pin 跨页。
- 一个 sheet pin 只承载一个语义；总线用总线名 + 范围。

## 层次标签 vs 全局标签

| 类型 | 作用域 | 用在哪 |
|---|---|---|
| 局部标签 | 当前页 | 页内连接 |
| 层次标签 | 当前页 ↔ 父页 sheet pin | 跨页信号 |
| 全局标签 | 全工程 | 电源、地、少数真全局（如 `RESET_GLOBAL`） |

误用全局标签会导致不同页同名网络被强行合并——这是最常见的"幽灵连接"来源。

## 位号与单元

- 功能块内位号连续（`R101–R109`），便于定位。
- 多单元器件（运放、门电路）用 `U1A/U1B`；未用单元接固定电平或 NC。
- 复制粘贴后必须重新 annotate，禁止重复位号。
- DNP 器件保留位号，BOM 标 DNP。

## 评审检查

1. `grep` 式检查：无 `Net-(` 自动名、无重复网络名。
2. 层次 pin 列表与页内标签逐一对齐。
3. 电源网在 power 页有源、有去耦、有测试点。
4. 跨页信号只走层次标签。
5. 位号无重复、无空号。
