# 叠层预设（概念表）

> 非板厂承诺。实际叠层、PP/芯板厚度、εr、铜厚以板厂报价/工程回复为准。

## 2 层（1.6mm）

| 层 | 角色 | 铜厚 |
|---|---|---|
| L1 | 信号 + 局部铺铜 | 1oz |
| L2 | 地/电源（混合） | 1oz |

- 参考不完整；高速信号慎用。
- 适合低速/低成本。

## 4 层（1.6mm，概念）

| 层 | 角色 | 厚度 |
|---|---|---|
| L1 | 信号 | 0.035mm |
| 介质 | PP | 0.20mm |
| L2 | GND | 0.035mm |
| 芯板 | — | 1.06mm |
| L3 | PWR | 0.035mm |
| 介质 | PP | 0.20mm |
| L4 | 信号 | 0.035mm |

厚度校验：`4×0.035 + 2×0.20 + 1.06 = 1.60mm`（不含阻焊/表面处理）。
- L1/L4 参考 L2/L3；阻抗可控。
- 电源平面与地平面成对。

## 6 层（1.6mm，概念）

| 层 | 角色 |
|---|---|
| L1 | 信号 |
| L2 | GND |
| L3 | 信号（高速） |
| L4 | PWR |
| L5 | GND |
| L6 | 信号 |

- L3 上下都有参考，适合高速。
- L4/L5 成对。
- 关键时钟优先 L3/L6。

## 阻抗目标

| 信号 | 目标 |
|---|---|
| 单端 | 50Ω |
| USB 2.0 | 90Ω 差分 |
| 以太网 | 100Ω 差分 |
| CAN | 120Ω 终端（非走线阻抗） |

## 使用方式

1. 选层数与板厚。
2. 用板厂叠层算 `w/s`。
3. 布线保持参考连续。
4. 下单前确认叠层与阻抗测试。
