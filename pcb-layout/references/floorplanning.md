# 功能分区与流向（floorplanning）

布局的第一步不是放器件，是决定**电流/信号从哪进、经过谁、从哪出**。

## 分区模板

```
┌─────────────────────────────────────────────┐
│ 接口区（USB/电源/CAN）   ESD/保护/滤波       │
│                                             │
│  电源区          数字区          模拟区      │
│  DCDC/LDO        MCU/存储        前端/基准   │
│  电感/大电容     总线/调试       滤波/屏蔽   │
│                                             │
│  RF 区（靠板边，按净空）    连接器/测试点    │
└─────────────────────────────────────────────┘
```

- 入口在一侧，出口在另一侧；不要让人"绕回去"。
- 电源区靠近入口，减少大电流路径长度。
- 模拟/RF 远离 DCDC、SW、时钟、连接器。
- 数字居中，靠近接口与调试口。

## 流向

连接器 → ESD/保护 → 滤波 → IC → 输出连接器。

- 单向、不交叉；必要时用一层"跨线"解决。
- 电源从入口到负载的路径最短；地去耦就近。
- 高速接口从连接器到 IC 尽量直，不绕板。

## 连接器

| 项 | 要求 |
|---|---|
| 位置 | 板边，插拔方向朝外 |
| 方向 | 与结构/外壳一致；防呆 |
| 应力 | 固定脚/定位柱，焊点不承受插拔力 |
| ESD | 靠近入口，先于被保护器件 |
| 差分 | 从连接器到 IC 路径最短、少换层 |

## 关键器件优先级

1. 连接器、安装孔、大件（电感、大电容）。
2. MCU/SoC、晶振、DCDC。
3. 去耦、保护、接口芯片。
4. 一般无源件。

每放一个大件，检查它是否挡住后续关键路径。

## 分区评审

- 功能块是否聚簇？同类器件是否对齐？
- 电源/地回流是否被切断？
- 模拟/RF 是否被数字/开关噪声包围？
- 接口到 IC 是否绕远？
- 测试点/调试口是否可达？

## 常见错误

| 错误 | 后果 |
|---|---|
| 连接器放板中间 | 插拔不便、走线绕 |
| DCDC 挨着模拟前端 | 噪声耦合 |
| 晶振远离 MCU | 时钟不稳 |
| 分区频繁穿插 | 回流混乱、难布线 |
| 只按"好看"对齐 | 忽略热/机械/回流 |
