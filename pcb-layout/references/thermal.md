# 热设计（thermal）

## 基本公式

`Tj = Ta + P × θJA`

- `θJA` 依赖封装、铜箔面积、过孔、气流、邻近器件。
- 手册的 θJA 通常是 JEDEC 板条件；实际板可能更差或更好。
- `Tj = Tc + P × θJC` 只在**热流主要经 case→散热器**时成立：`Tc` 是手册定义位置的壳温，
  `P` 是流经该路径的功率，不能把总功耗直接代入。
- 用封装顶部温度估算时，应使用 `ΨJT`（结到顶）：`Tj ≈ Tt + P × ΨJT`，并注意其测试条件；
  `θJC` 与 `ΨJT` 不是同一个量，不能互相替代。

## 判据

- `Tj ≤ Tj_max(手册) − 裕量`，裕量用 K（例如 ≥20 K 或按项目要求）。
- 不用摄氏比例（`Tj/Tj_max`）作判据：温标零点会改变结论。
- 环境温度按机箱内最坏值，不是室温。

## 铜箔与过孔

- 铜箔面积越大，θJA 越低；按手册曲线或实测。
- 散热焊盘：先确认电位（GND/负电源/浮空），再决定是否打地过孔。
- 热过孔：0.3mm 阵列，连接到对应铜面；过孔数量按热阻估算。
- 大电流铜箔同时承载电流与散热，两者都要满足。

## 布局策略

| 策略 | 做法 |
|---|---|
| 分散热源 | 功率器件分开，避免热点叠加 |
| 热敏件远离 | 晶振、基准、传感器远离 DCDC |
| 气流 | 沿气流方向排布；不要挡风道 |
| 外壳 | 导热垫/金属壳接触；注意绝缘 |
| 热循环 | 避免刚性连接处应力集中 |

## 常见错误

1. 用 25°C 室温代替机箱内温度。
2. 忽略铜箔面积对 θJA 的影响。
3. 散热焊盘默认接地（可能是负电源/浮空）。
4. 只看平均功率，忽略峰值/瞬态。
5. 热敏件放在 DCDC 电感旁。
6. 没有留温度裕量，量产批次超限。
