# 摆放规则（placement-rules）

## 去耦

- 每个电源脚 100nF（`HEURISTIC`，手册优先）；大电容按电源域。
- 距离 ≤2–3mm（`HEURISTIC`）；地过孔就近，回路面积最小。
- 先小后大、先近后远；不要放在板另一面远距离。
- 多电源脚：每个脚一个，或按手册共享。

## 晶振

- 紧贴 MCU（≤5mm，`HEURISTIC`）；走线短、等长。
- 下方不走线、不铺铜（按器件要求）；包地。
- 负载电容对称、接地就近；远离 DCDC/SW/时钟输出。
- 晶振外壳接地（如适用）。

## 开关电源

- 输入电容紧贴 Vin/GND；hot loop（输入电容→高侧→低侧→回电容）最小。
- 电感靠近 SW，SW 铜箔小而短；反馈开尔文、远离电感。
- 输出电容靠近负载/输出连接器。
- 地平面单点汇合，避免开关电流穿过敏感地。

## 连接器与保护

- 板边、朝外；固定脚/定位柱。
- ESD 靠近入口，先于被保护器件；TVS 走线短。
- 差分对从连接器到 IC 尽量直、少换层。

## IC 与无源件

- IC 方向一致（pin1 标识可见）；同类对齐。
- 无源件按功能块聚簇，值标注可读。
- 大件不要挡测试点/调试口/散热路径。
- 高热器件分散，热敏件远离。

## 热与机械

- 功率器件铜箔面积/thermal via 按热阻核算。
- 安装孔禁布区 ≥6mm（M3，`HEURISTIC`）；板边 ≥3–5mm。
- 高器件按外壳包络；连接器插拔空间。
- V-cut/拼板区域禁布。

## 评审指标

| 指标 | 目标 |
|---|---|
| 重叠 | `pcb_overlap` 无 block |
| 去耦距离 | 关键脚 ≤2–3mm |
| 晶振距离 | ≤5mm 且包地 |
| 板边距 | ≥3–5mm |
| 安装孔禁布 | ≥6mm |
| 热间距 | 按 Tj 核算 |

`score_placement` 的扣分项要逐条解释；"分数低但合理"也要记录理由。

## 反模式

1. 先布线后补去耦。
2. 晶振放在板边/连接器旁。
3. DCDC 电感靠近模拟前端。
4. 大电容离负载很远。
5. 测试点被高器件挡住。
6. 为对齐牺牲回流/热。
