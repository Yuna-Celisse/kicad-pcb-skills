# 叠层设计（stackup-design）

## 层角色

| 层数 | 叠层（示例） | 说明 |
|---|---|---|
| 2 | Sig / GND+PWR | 低成本；参考不完整 |
| 4 | Sig / GND / PWR / Sig | 通用；阻抗可控（示例厚 1.60mm） |
| 6 | Sig / GND / Sig / PWR / GND / Sig | 高速/混合信号 |

原则：

- 每个信号层邻接完整参考平面。
- 电源平面与地平面成对，减少平面谐振。
- 不要把两个信号层直接相邻（除非有目的）。
- 参考平面不要被分割线切断关键信号。

## 厚度与阻抗

- 板厚 1.6mm 最常见；1.0/0.8mm 用于薄型。
- 阻抗由线宽、介质厚度、εr、铜厚决定；与板厂叠层一起定。
- 常见目标：单端 50Ω；USB 90Ω；以太网 100Ω；CAN 120Ω（终端，不是走线阻抗）。
- 下单前确认 PP/芯板组合与总厚。

## 4 层示例（概念）

```
L1  Sig        0.035mm 铜
    PP         0.20mm
L2  GND        0.035mm
    芯板       1.06mm
L3  PWR        0.035mm
    PP         0.20mm
L4  Sig        0.035mm
```

厚度校验：`4×0.035 + 2×0.20 + 1.06 = 1.60mm`（不含阻焊）。
实际厚度以板厂为准；上表只用于说明"参考层相邻"。

## 6 层示例（概念）

```
L1 Sig   L2 GND   L3 Sig   L4 PWR   L5 GND   L6 Sig
```

- L3 与 L2/L4 相邻，适合高速。
- L4 电源与 L5 地成对。
- 关键时钟走 L3 或 L6，避免跨分割。

## 阻抗与叠层联动

1. 先定目标阻抗与叠层。
2. 用板厂/场求解器算线宽/间距。
3. 布线时保持参考连续。
4. 换层/换参考重新核算。
5. 测试 coupon 随板。

公式估算见 `../../pcb-routing/references/impedance.md`。

## 常见错误

- 先定线宽再凑叠层。
- 信号层与参考层之间夹信号层。
- 电源平面开槽导致回流绕行。
- 忽略绿油/铜厚对阻抗的影响。
- 不同板厂叠层不重新核算。
