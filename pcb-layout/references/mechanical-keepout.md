# 机械与禁布（mechanical-keepout）

## 安装孔

| 螺钉 | 孔径 | 禁布直径（`HEURISTIC`） |
|---|---|---|
| M2 | 2.2mm | ≥4.5mm |
| M2.5 | 2.7mm | ≥5.5mm |
| M3 | 3.2mm | ≥6.0mm |
| M4 | 4.3mm | ≥8.0mm |

- 禁布区内不放器件/走线/铜（按结构/板厂要求）。
- 金属螺钉 + 接地焊盘时注意短路/ESD；是否需要绝缘垫。
- 安装孔到板边距离按结构；避免孔边开裂。

## 板边

- 器件/走线距板边 ≥3–5mm（`HEURISTIC`），按铣刀/公差。
- 板边铜/阻焊开窗按板厂能力。
- 拼板 V-cut 两侧留 5mm 工艺边，槽线禁布。
- 邮票孔/桥连区域禁布。

## 连接器

- 插拔方向朝外；外壳开孔与连接器对齐。
- 固定脚/定位柱承受插拔力；焊盘不承受。
- 高连接器留装配/手指空间；注意与上方板/外壳干涉。
- 连接器针序/方向与线束一致。

## 高度与包络

- 按外壳 3D 包络检查最高器件。
- 屏蔽罩/散热器留安装与导热空间。
- 器件不要超出板框；拼板时注意相邻板干涉。

## 拼板

- Mark 点 3 个、非对称、阻焊开窗。
- 工艺边 5mm；V-cut 直线、深度一致。
- 阴阳板评估工艺与支撑。
- 分板应力远离器件（尤其陶瓷电容/晶振）。

## 3D 与结构评审

1. 板框/孔位与结构图一致。
2. 连接器/按键/指示灯位置与外壳一致。
3. 高度不干涉；装配顺序可行。
4. 螺钉/铜柱不短路。
5. 拼板/V-cut 不伤器件。

## 常见错误

- 安装孔禁布区放了走线/铜。
- 连接器太靠内，插头插不到。
- 高器件挡住外壳卡扣。
- 板边走线被铣边切到。
- V-cut 处放陶瓷电容，分板开裂。
