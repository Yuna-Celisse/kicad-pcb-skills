# 回流路径（return-path）

## 基本事实

每条信号电流都要回流；回流走**电感最小**的路径，通常是最邻近的参考平面。

- 信号在 L1、参考在 L2：回流在 L2 上、正对走线。
- 换层：按 §换层 的三种情形处理（同参考 / 换电位 / 隔离边界），不能默认加地孔。
- 跨分割：回流被迫绕行，环路面积增大 → 辐射/敏感度上升。

## 跨分割

| 场景 | 风险 | 处理 |
|---|---|---|
| 信号跨 GND 分割 | 回流绕行 | 改参考/换层/加缝合 |
| 信号跨 PWR 分割 | 同上 | 电源平面完整化 |
| 连接器地针不足 | 回流路径长 | 增加地针/屏蔽 |
| 晶体/模拟跨数字地 | 噪声耦合 | 单点汇合/分区 |

原则：**能不跨就不跨**；**非隔离**分割必须跨时，在跨点附近提供回流桥（电容/地孔）；
隔离边界不得默认桥接，只能按安规设计单独验证。

## 换层

换层必须看**新参考面是什么**，不能一律加地孔：

| 情形 | 回流路径 | 处理 |
|---|---|---|
| 同参考（L1→L4，均参考 GND） | 同一 GND 平面 | 过孔旁加地孔，保持连续 |
| 参考换电位（GND→PWR） | 需在 GND/PWR 间就近提供高频转移 | 用去耦电容/平面电容就近跨接，或改层/改参考；**单个地孔不能连通 PWR 与 GND** |
| 隔离边界 | 不允许常规回流跨越 | 保持隔离带；桥接只按安规设计（如 Y 电容）并单独验证 |

- 优先让信号全程参考同一 GND；换参考是最后手段。
- 差分对换层：两孔对称，回流路径按上表处理。
- 高速信号避免多次换层。
- 任何"跨参考"处理都要在阻抗/去耦设计里验证，不能默认加孔了事。

## 连接器与电缆

- 连接器地针尽量多、靠近信号针。
- 屏蔽层/外壳接地按结构；避免"猪尾巴"。
- 电缆屏蔽与板地 360° 连接（如可行）。

## 地平面

- 完整地平面优先；分割只在明确需要时（模拟/数字、隔离）。
- 分割时关键信号不跨；**非隔离**分割处可加回流桥；隔离边界不得默认桥接。
- 地过孔缝合沿边界/板边。

## 检查清单

1. 每条高速信号下方有完整参考？
2. 同参考换层有地孔；换参考有经验证的转移路径？
3. 有无跨分割？跨了是否有桥？
4. 连接器地针够不够？
5. 晶振/模拟回流是否独立？
6. 电源平面开槽是否切断回流？

## 常见错误

- 只看信号线，不看回流。
- 用"包地"代替完整参考。
- 跨分割后加 0Ω/电容"补救"却不改布局。
- 地平面被过孔/开槽切碎。
