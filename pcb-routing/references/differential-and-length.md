# 差分与等长（differential-and-length）

## 差分对

- 等宽、等距、同层、同参考；从连接器到 IC 尽量直。
- 少换层；同参考换层时两侧对称加回流地孔；换参考按 [return-path.md](return-path.md) 的表格处理。
- 差分对与其他信号保持 ≥3W（或按串扰仿真）。
- 不要在一对中间穿其他信号。
- 终端/共模按协议（USB/CAN/以太网）。

## 对内 skew

| 协议 | 典型要求 |
|---|---|
| USB 2.0 | 对内 ≤ 50mil（按规范/器件） |
| USB 3 | 更严，按协议 |
| 以太网 | 对内严格，按 PHY 手册 |
| CAN | 通常不要求严格等长 |

以协议/器件手册为准；上表只是量级。

## 等长组

- 只有协议要求时才做组内等长（DDR、并行总线、多 lane）。
- 先定基准（时钟/选通），再匹配数据/地址。
- 在**失配产生处附近**补偿；具体位置服从接口拓扑与器件指南，不强制放在接收端。
- 蛇形幅度小、间距大，减少串扰与损耗。
- 长度按"电气长度"（含过孔/封装）估算，不只看走线。

## 蛇形规则

| 项 | 建议 |
|---|---|
| 幅度 | 尽量小（≤3× 线宽） |
| 间距 | ≥3W |
| 位置 | 靠近失配处；按器件/接口指南 |
| 数量 | 少而长，不要密集小弯 |
| 参考 | 下方参考完整 |

## 过孔

- 差分对过孔成对；同参考时地孔就近，换参考按 [return-path.md](return-path.md)。
- 过孔尽量少；换层处阻抗不连续。
- 反焊盘按阻抗设计；不要随意加大。

## 常见错误

1. 对内不等长却做组内蛇形。
2. 蛇形远离失配处，或压到参考/间距。
3. 差分对中间穿线。
4. 同参考换层不加地孔；换参考未验证转移路径。
5. 只看 2D 长度，忽略过孔/封装。
6. 盲目追求"完全等长"，忽略协议容差。
