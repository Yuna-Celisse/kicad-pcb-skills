# 铺铜与过孔（pour-and-via）

## 铺铜

### 基本设置

| 项 | 建议 |
|---|---|
| 网络 | GND（分区时按地类型） |
| 层 | 双面 GND（或按叠层） |
| 优先级 | 低于信号；最后填 |
| 清除间距 | ≥ 板厂最小 + 余量 |
| Thermal relief | 焊接/返修需要时开；大电流连接用 solid |
| 孤岛 | 删除（或按需要保留） |

### 阶段划分（不是"永远最后"）

| 阶段 | 可以做什么 | 不能做什么 |
|---|---|---|
| 布线前/中 | 建立参考平面、定义 zone、填充以提供回流参考 | 用最终铺铜掩盖未布通 |
| 改线后 | 重新填充 zone（KiCad 支持重填/自动重填），检查孤岛 | 让 zone 与走线长期不一致 |
| 最终验收 | 全板铺铜、缝合孔、重填、清孤岛、DRC | 把未重填的 zone 当最终状态 |

**最终填充**在布线完成后验收；但**参考平面**应尽早建立，否则阻抗与回流无从保证。

### 常见问题

- 孤岛：未连接的铜，删除或加过孔。
- 细颈：铺铜连接过窄，载流不足。
- 跨分割：铺铜连接不同地，造成噪声耦合。
- Thermal 不足：大电流焊盘散热/载流不够。
- 板边间距不足：铣边短路。

## 过孔

### 类型

| 类型 | 用途 | 注意 |
|---|---|---|
| 通孔 | 通用 | 环宽/钻孔 |
| 盲孔/埋孔 | 高密度 | 成本/工艺 |
| 盘中孔 | BGA 扇出 | 需树脂塞孔/电镀填平 |
| 散热孔 | 热焊盘 | 按电位连接 |

### 载流与缝合

- 电源/地：多孔并联；按电流/温升估算。
- 缝合孔：沿地平面边界/板边，间距按最高频率（λ/20 量级）。
- 晶振/屏蔽罩：周围多孔。
- 过孔不要切断参考平面上的关键回流。

### 环宽

- 环宽 ≥ 板厂最小（常见 0.15mm，按能力）。
- 反焊盘按阻抗/工艺；不要随意加大。
- 过孔间距满足 DRC。

## 评审

1. 参考平面是否提前建立？最终铺铜是否在布通后重填/验收？有无孤岛？
2. 大电流路径是否靠铺铜/多孔？
3. 缝合孔是否足够？
4. 过孔是否切断回流？
5. 盘中孔是否塞孔？
6. 板边/禁布区是否清空？

## 反模式

- 用最终铺铜"修"未布通。
- 改线后不重填 zone，拿旧铜当最终状态。
- 铺铜连接数字地/模拟地造成耦合。
- 过孔数量不足导致压降/接地阻抗。
- 盘中孔不塞孔导致焊接不良。
- 缝合孔间距过大，屏蔽失效。
