# 阻抗（impedance）

## 微带（外层）

```
Z0 ≈ 87 / sqrt(εr + 1.41) · ln(5.98h / (0.8w + t))
```

- `h`：介质厚度；`w`：线宽；`t`：铜厚；`εr`：介质常数。
- 适用约 `0.1 < w/h < 2`；超出误差变大。

## 带状线（内层）

```
Z0 ≈ 60 / sqrt(εr) · ln(4b / (0.67πw(0.8 + t/w)))
```

- `b`：两参考平面间距。
- 内层需要上下完整参考。

## 差分（近似）

```
Zdiff ≈ 2 · Z0 · (1 − 0.48 · exp(−0.96 · s/h))
```

- `s`：差分间距；`h`：介质厚度。
- 强耦合时用场求解器；上式只作起点。

## 算例（微带 50Ω）

`εr=4.3, h=0.20mm, w=0.35mm, t=0.035mm`：

```
5.98h = 1.196；0.8w + t = 0.315；比值 ≈ 3.80，ln ≈ 1.334
sqrt(4.3+1.41) ≈ 2.39
Z0 ≈ 87/2.39 × 1.334 ≈ 48.6Ω
```

接近 50Ω，但仍需用板厂叠层/场求解器微调。

## 实际流程

1. 定叠层与目标阻抗（50/90/100Ω）。
2. 用板厂或场求解器算 `w/s`。
3. 布线保持参考连续，不跨分割。
4. 换层/换参考重新核算。
5. 测试 coupon 随板；量产抽测。

## 参考平面

- 阻抗线下方必须是完整参考（GND 优先）。
- 参考平面开槽 → 阻抗突变/回流绕行。
- 跨分割是首要风险；优先改参考/改层，按 [return-path.md](return-path.md) 的换层表处理
  （同参考加地孔；换电位需去耦转移；隔离边界不桥接）。

## 误差来源

| 来源 | 影响 |
|---|---|
| 叠层厚度公差 | ±10% |
| εr 批次 | ±0.2 |
| 铜厚/绿油 | 小 |
| 线宽蚀刻 | ±10% |
| 公式适用域 | 大 |

结论：公式用于估算，投板前以板厂阻抗计算/场求解为准；不要宣称"精确 50Ω"。
