# 载流与线宽（current-and-width）

## IPC-2221 近似

```
I = k · ΔT^0.44 · A^0.725
```

- `I`：电流（A）
- `ΔT`：允许温升（°C）
- `A`：铜截面积（mil²）
- `k`：外层 0.048，内层 0.024

反解：

```
A = (I / (k · ΔT^0.44))^(1/0.725)
width(mil) = A / thickness(mil)
```

1oz 铜厚 ≈ 1.37mil（35µm）；2oz ≈ 2.74mil。

## 估算表（外层，1oz）

| 电流 | ΔT=10°C | ΔT=20°C |
|---|---|---|
| 1A | 0.30mm | 0.20mm |
| 3A | 1.37mm | 0.90mm |
| 5A | 2.78mm | 1.83mm |

内层同条件约需 2.5–3× 宽度（散热差）。

> 上表是按公式的**估算**，未计铜箔实际厚度、阻焊、气流与邻近走线；
> 关键电源以温升实测/板厂数据为准。

## 算例（3A，10°C，外层 1oz）

```
ΔT^0.44 = 10^0.44 ≈ 2.754
A = (3 / (0.048 × 2.754))^(1/0.725) ≈ 74 mil²
width = 74 / 1.37 ≈ 54 mil ≈ 1.37mm
```

压降：`Vdrop = I × R`，`R = ρ × L / A`；长距离大电流要同时看压降。

## 过孔

- 过孔载流按孔径/镀铜厚度/温升；不要只按"一个孔 1A"估算。
- 电源/地：多孔并联，靠近电容与器件。
- 大电流：过孔阵列 + 铺铜；避免单孔。
- 环宽/反焊盘按板厂能力。

## 铺铜

- 大电流优先铺铜（宽而短），不是无限加宽走线。
- 铺铜要能承载回流；不要用细颈连接。
- 多相/多层并联时注意均流。

## 降额

- 线宽/铜厚按最坏温度与最大电流。
- 不要贴板厂最小线宽；留 ~20% 余量。
- 保险丝/连接器/电感各自的额定与降额单独核。

## 常见错误

1. 只算平均电流，忽略峰值/启动。
2. 内层用外层表格。
3. 过孔数量不足。
4. 只看温升不看压降。
5. 铺铜细颈成为瓶颈。
6. 忽略连接器/端子的额定电流。
