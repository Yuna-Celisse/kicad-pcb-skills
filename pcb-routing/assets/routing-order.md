# 布线顺序（routing-order.md）

按顺序做，每步完成再进下一步。

## 0. 准备

- [ ] 布局冻结；板框/叠层/阻抗目标确定。
- [ ] netclass 已定义并套到网络。
- [ ] 板厂能力（线宽/间距/孔径/环宽）确认。
- [ ] DRC 规则能指回 Design Intent。

## 1. 电源与地

- [ ] 大电流路径（输入→DCDC/LDO→负载）。
- [ ] 电源平面/铺铜策略确定。
- [ ] 去耦/大电容就近。
- [ ] 地回流路径规划（不跨分割）。

## 2. 关键信号

- [ ] 时钟（短、包地、少换层）。
- [ ] 复位/BOOT/调试。
- [ ] 差分（USB/CAN/以太网）。
- [ ] 高速总线（按协议等长）。
- [ ] 模拟/基准（远离数字/开关）。

## 3. 一般信号

- [ ] 最短路径；少过孔。
- [ ] 避免与关键信号长距离平行。
- [ ] 连接器到 IC 不绕远。

## 4. 铺铜与缝合（最终验收）

- [ ] 参考平面/zone 可在布线前建立，改线后重填。
- [ ] 布通后做最终 GND 铺铜（双面）。
- [ ] 清孤岛/细颈。
- [ ] 缝合孔（板边/地平面边界）。
- [ ] 最终重填 zone 并检查。

## 5. 收尾

- [ ] unconnected=0。
- [ ] DRC 跑过；违规已处理/记录。
- [ ] 丝印不压焊盘；位号可读。
- [ ] 测试点/调试口可达。
- [ ] P7/P8 Gate 已跑并记录。

## 禁止

- 用最终铺铜掩盖未布通。
- 改线后不重填 zone。
- 改 netclass 后不重跑 DRC。
- 在 P7 之前宣布"布线完成"。
