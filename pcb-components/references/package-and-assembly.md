# 封装与装配（package-and-assembly）

## 封装选择

| 封装 | 间距 | 手焊 | 备注 |
|---|---|---|---|
| 0603 | 0.8mm | 可以 | 手焊下限推荐 |
| 0402 | 0.5mm | 困难 | 需镊子/放大镜 |
| 0201 | 0.3mm | 不建议 | 需贴片 |
| SOIC/TSSOP | 0.65–1.27mm | 可以 | 引脚外露 |
| QFN | 0.4–0.65mm | 需热风/回流 | 散热焊盘 |
| BGA | 0.4–0.8mm | 回流 | 需 X-ray |
| 连接器 | — | 视类型 | 优先机械固定 |

## 焊盘与钢网

- 焊盘按 IPC-7351 或厂家推荐；不要随意改小。
- 钢网厚度：0.12mm（0402 及以上）、0.10–0.12mm（细间距）。
- QFN 散热焊盘：开窗分区/网格，避免立碑/偏移。
- 阻焊桥：细间距需确认板厂能力。

## 散热

- QFN/BGA 散热焊盘**先按手册确认电位**：可能是 GND、负电源，或电气浮空。
- 只有确认应接地时才打地过孔（0.3mm 阵列）到地平面；负电位/浮空按手册处理
  （接对应电源、隔离或不开窗），不能由封装类别推断。
- 大功率器件铜箔面积按热阻计算；必要时开窗加锡。
- 热敏器件远离热源；注意热循环应力。

## 连接器与机械

- 优先带定位柱/机械固定脚；插拔力由结构承担，不由焊点承担。
- 板边连接器留应力释放；避免板边 V-cut 处受力。
- 连接器方向、针序、防呆与结构图核对。
- 高连接器注意外壳高度与装配顺序。

## 焊接与工艺

| 工艺 | 注意 |
|---|---|
| 回流 | 温区按焊膏；器件耐温（MSL） |
| 手焊 | 0603 以上；QFN 用热风 |
| 波峰 | 只适合插件/选择性 |
| 返修 | BGA 需返修台；QFN 热风 |

- MSL 等级与烘烤要求；潮湿敏感器件受潮会爆米花。
- 立碑：小封装两端热不平衡；焊盘/走线对称。
- 偏移：钢网开孔与贴片精度；Mark 点。

## 拼板与分板

- V-cut：直线、深度一致；两侧留 5mm 工艺边。
- 邮票孔：孔径/孔距按板厂；分板应力。
- Mark 点：3 个、非对称、阻焊开窗。
- 阴阳板风险：工艺边/支撑；确认板厂能力。

## 装配检查

- [ ] 封装与焊盘匹配（IPC-7351/厂家）。
- [ ] 散热焊盘电位已按手册确认（GND/负电源/浮空）。
- [ ] 极性器件有丝印标识（二极管、钽电容、IC pin1）。
- [ ] 连接器方向/针序与结构一致。
- [ ] 高器件不挡测试点/外壳。
- [ ] 钢网/贴片能力覆盖最细间距。
- [ ] MSL/烘烤要求已传达。
- [ ] 拼板/V-cut/工艺边符合板厂规则。

## 与 DFM 的关系

封装选择直接影响 DFM：间距、环宽、阻焊桥、孔径。投板前用
`pcb-manufacturing` 的 DFM 矩阵复核；本文件只保证"选得对"，不替代 DFM 检查。
