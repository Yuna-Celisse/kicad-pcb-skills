# 无源件选择（passive-selection）

## 陶瓷电容介质

| 介质 | 容差 | 温漂 | 电压系数 | 用途 |
|---|---|---|---|---|
| C0G/NP0 | ±1–5% | ~0 | 极小 | 定时、滤波、采样、谐振 |
| X7R | ±10% | ±15% | 中 | 去耦、通用 |
| X5R | ±10% | ±15% | 中 | 去耦（温度范围窄） |
| Y5V/Z5U | +22/−82% | 大 | 大 | 仅限不敏感旁路（不推荐） |

规则：

- 定时/振荡/ADC 采样/高精度滤波：C0G。
- 去耦：X7R/X5R；按 DC bias 后的有效容量核。
- 避免 Y5V 做去耦/定时；容量随温度/电压崩。
- 高压场合看额定电压与介质组合（如 X7R 100V 大封装）。

## 容差与精度

| 用途 | 建议容差 |
|---|---|
| 分压/采样 | 0.1–1% |
| 定时 RC | 1–5%（配合 C0G） |
| 去耦 | 10–20% |
| 耦合/旁路 | 10–20% |

## DC bias

- 高容值小封装（10µF 0603/0805）在额定电压附近可能掉 50–80%。
- 按厂家曲线取"工作电压下的有效容量"，再核纹波/稳定性。
- 需要大容量时：加大封装、提高耐压、并联、或改钽/聚合物。

## ESR / ESL

- 开关电源输出：ESR 影响纹波与稳定性；聚合物/钽/陶瓷各有适用。
- 高频去耦：小封装 ESL 低，靠近引脚。
- 大容量电解：注意 ESR 随温度/寿命上升。

## 电解电容

- 耐压 ≥ 1.25×；纹波电流满足；105°C 长寿命优先。
- 寿命按 `L = L0 × 2^((T0−Ta)/10)` 折算。
- 极性/防爆槽/安装方向；避免靠近热源。

## 电感

| 参数 | 要点 |
|---|---|
| 电感量 | 按纹波/频率计算 |
| Isat | ≥ 1.3× 峰值 |
| Irms | 温升电流 ≥ 工作电流 |
| DCR | 压降与损耗；大电流选低 DCR |
| 屏蔽 | 开关电源优先屏蔽 |

- 饱和电流与温升电流不是同一个值，两者都要满足。
- 多相/大电流：并联需均流设计。

## 磁珠

- 看目标频段阻抗与 DC bias 后的衰减；DCR 影响压降。
- 不要用磁珠做电源滤波的唯一手段；配合电容。
- 高频磁珠的额定电流要留余量。

## 电阻

| 类型 | 用途 | 注意 |
|---|---|---|
| 厚膜 | 通用 | 脉冲/浪涌能力有限 |
| 薄膜 | 精密/低噪声 | 成本高 |
| 合金/分流 | 电流检测 | TCR、功率、开尔文 |
| 排阻 | 密集上拉/限流 | 功耗按整体 |

- 功率按 50–60% 降额；脉冲按曲线。
- 高压场合看额定电压（不仅是功率）。
- 分流电阻用开尔文走线，避免铜阻计入。
