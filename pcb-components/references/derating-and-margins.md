# 降额与余量（derating-and-margins）

降额 = 让器件工作在**额定值以下**，以换取寿命、温升与批次差异余量。
绝对最大额定值不是工作点；禁止按 abs max 设计。

## 基线

| 器件 | 最低降额 | 备注 |
|---|---|---|
| 电阻 | 功率 ≤ 50–60% | 脉冲/浪涌另算 |
| 陶瓷电容 | 耐压 ≥ 1.5–2× | 计入 DC bias |
| 电解电容 | 耐压 ≥ 1.25× | 纹波电流、寿命 |
| 电感 | Isat ≥ 1.3× 峰值 | DCR 压降/温升 |
| 二极管 | Vr ≥ 1.5–2× | 雪崩/浪涌 |
| MOS | Vds ≥ 1.5–2× | SOA 另算 |
| 三极管 | Vce ≥ 1.5–2× | 二次击穿 |
| 连接器 | 电流 ≥ 1.5× | 每 pin 与整体 |
| TVS | Vclamp < 被保护 abs max | 峰值功率 |
| 结温 | `Tj ≤ Tj_max(手册) − 裕量` | 裕量用 K，不用摄氏比例 |

数据手册更严时以手册为准。除 TVS/结温直接来自手册外，上表倍率属于
`HEURISTIC`（行业惯例），项目正式采用时应登记为 candidate 并注明来源。

## 算例

### 电阻功率

`P = I²R = V²/R`

例：12V 加在 100Ω 上 → `P = 1.44W`；按 60% 降额需 `≥ 2.4W` → 选 3W。
脉冲：按脉冲功率-时间曲线，不要用平均功率代替。

### 陶瓷电容

1. 耐压：`Vrated ≥ 1.5–2 × Vwork`。
2. DC bias：10µF/6.3V/0603 在 5V 下可能只剩 40–60%；按手册曲线取实际值。
3. 温度：X7R 覆盖 −55–125°C；Y5V 容量随温度大幅下降，不做定时/滤波。
4. 有效容量 = 标称 × DC bias 系数 × 温度系数 × 老化系数。

### 电解电容寿命

`L = L0 × 2^((T0 − Ta)/10)`

例：2000h @105°C，工作在 85°C → `2000 × 2² = 8000h`。
同时核纹波电流与 ESR 发热。

### 电感

- 峰值 `Ipk = Iout + ΔIL/2`；Isat ≥ 1.3 × Ipk。
- DCR 压降 `Vdrop = Iout × DCR`；温升按手册曲线。
- 饱和后电感量骤降，注意短路/启动瞬态。

### 二极管 / MOS

- 反向电压含开关尖峰（示波器实测或按漏感估算）。
- MOS 看 `Vds`、`Id`、`Rds(on)@Vgs`、栅极电荷、SOA。
- 体二极管反向恢复影响效率/EMI。

### 结温

`Tj = Ta + P × θJA`（或按 θJC + 散热器）

例：P=0.5W，θJA=60°C/W，Ta=40°C → Tj=70°C；手册 `Tj_max=125°C` →
裕量 `125 − 70 = 55 K`，满足“低于手册上限并留出裕量”的要求。

**不要用 `Tj/Tj_max` 的摄氏比例**：摄氏零点任意，70/125=0.56 与换算成 Kelvin
后的比值不同，结论会随温标变化。判据必须是“手册上限 + 绝对温度裕量（K）”。

θJA 依赖铜箔面积与气流，按实际布局修正；高温环境要按降额后的 θJA 重算。

### 连接器

- 每 pin 额定电流 × 降额 ≥ 实际；多 pin 并联时按厂家降额曲线。
- 温升、插拔次数、接触电阻也要核。

### TVS

- 工作电压 > 信号最大电压；钳位电压 < 被保护脚 abs max。
- 峰值脉冲功率按浪涌波形（8/20µs 等）核算；结电容匹配速率。

## 余量与证据

| 数值 | 来源 | 记录方式 |
|---|---|---|
| 额定值 | 数据手册（版本/页码） | 选型记录 |
| 实际应力 | 计算/仿真/实测 | 计算式 + 假设 |
| 余量 | 计算 | `margin = rated/actual` |

`HEURISTIC` 的余量（如 1.5×）必须在 BOM/记录中标注来源，不能伪装成手册值。

## 常见错误

1. 用标称电容值代替 DC bias 后的有效值。
2. 电感只看 Isat 不看 DCR。
3. 连接器按整排电流选，忽略单 pin。
4. TVS 只看工作电压不看钳位。
5. Tj 用 25°C 环境算，忽略机箱温升。
6. 把"实验室没坏"当作降额合格。
