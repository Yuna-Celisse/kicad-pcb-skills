# 有源器件选择（active-and-ic-selection）

## 电源

| 类型 | 适用 | 关键参数 |
|---|---|---|
| LDO | 小压差、低噪声、小电流 | 压差、静态电流、PSRR、噪声、稳定性 |
| Buck | 高压差、大电流 | 效率、开关频率、电感/电容、补偿 |
| Boost | 升压 | 占空比、电流限、肖特基/同步 |
| 电荷泵 | 小电流、反相/倍压 | 输出阻抗、纹波 |

- LDO：核 `P=(Vin−Vout)I` 与结温；陶瓷电容稳定性（老器件需 ESR）。
- Buck：hot loop、SW 节点、反馈开尔文；轻载模式。
- 多电源域：上电时序、PG、EN 链。

## MCU / SoC

检查清单：

- [ ] 外设数量（UART/SPI/I2C/ADC/PWM）与引脚复用。
- [ ] 封装与可用 GPIO；调试口。
- [ ] 供电域与去耦要求；内核/IO 电压。
- [ ] 时钟源（内部/外部）、精度。
- [ ] 启动模式、BOOT 脚。
- [ ] 供货与生命周期；替代型号。
- [ ] 工具链/烧录器支持。

## 接口

| 接口 | 选型要点 |
|---|---|
| USB-UART | 电平、流控、驱动能力 |
| USB-C PD | PD 控制器、CC 逻辑、VBUS 开关 |
| CAN | 收发器 5V/3.3V、隔离、共模 |
| RS-485 | 隔离、终端、失效保护 |
| Ethernet | PHY 与变压器、时钟 |
| I²C 缓冲 | 总线电容/地址冲突 |

## 保护

- ESD：结电容与速率匹配；靠近入口。
- 过流：保险丝/PPTC/限流开关；额定 ≥1.5×。
- 过压：TVS/OVP 控制器；钳位 < abs max。
- 反接：P-MOS/理想二极管；Vgs 耐压。
- 隔离：数字隔离器/隔离电源；安规距离。

## 逻辑与模拟

- 逻辑：电平匹配、输入阈值、驱动电流、传播延迟。
- 运放：带宽、压摆率、失调、噪声、轨到轨、负载。
- ADC/DAC：分辨率、采样率、输入范围、基准。
- 基准：初始精度、温漂、噪声、长期漂移。

## 热与封装

- 计算 `Tj = Ta + P × θJA`；QFN 看散热焊盘与过孔。
- 大功率器件优先低热阻封装 + 铜箔/散热器。
- 注意引脚间距与爬电距离（高压）。

## 供货与替代

- 优先 pin-compatible 多源；避免 NRND/EOL。
- 替代料核对：封装、引脚、极性、电压/电流、时序、温度等级。
- 关键器件至少一个已确认替代；写入选型记录。

## 选型记录字段

```
功能, 型号, 厂家, 封装, 关键参数, 降额核算, 数据手册(版本/日期),
库存/交期, 生命周期, 替代料, 结论
```

`HEURISTIC` 的判断（如"优先低静态电流"）要标注，不能写成手册结论。
